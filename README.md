# Reminder — προσωπικές υπενθυμίσεις

Μια ελληνόφωνη, μπλε/σκούρα PWA για επαναλαμβανόμενες και μεμονωμένες υπενθυμίσεις.

## Πρώτη έκδοση
- Προσθήκη, αλλαγή, διαγραφή και παύση υπενθυμίσεων.
- Επανάληψη: μία φορά, καθημερινά, εργάσιμες, εβδομαδιαία, μηνιαία.
- Αποθήκευση **τοπικά στη συσκευή** και εξαγωγή/εισαγωγή αντιγράφου JSON.
- Δοκιμαστική ειδοποίηση συστήματος με άδεια του χρήστη.
- Χρονικές ειδοποιήσεις μόνο όσο η εφαρμογή παραμένει ανοικτή.
- PWA manifest και service worker, με υποστήριξη λήψης πραγματικών Web Push όταν συνδεθεί εξωτερική υπηρεσία αποστολής.

**Σημαντικό:** Αυτή η έκδοση **δεν στέλνει ακόμη υπενθυμίσεις όταν η εφαρμογή είναι κλειστή** και **δεν συγχρονίζει** συσκευές. Για αυτά χρειάζεται backend (π.χ. Supabase με scheduler και Web Push/VAPID). Μην θεωρείτε ότι οι υπενθυμίσεις αποτελούν αξιόπιστο συναγερμό μέχρι να υλοποιηθεί και να ελεγχθεί η αποστολή push.

## Δημοσίευση
GitHub → Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save. Η αναμενόμενη διεύθυνση είναι `https://seemsfunny21.github.io/reminder/` όταν ολοκληρωθεί η δημοσίευση.

## Δεδομένα και ιδιωτικότητα
Δεν υπάρχει σύνδεση λογαριασμού ή αποστολή δεδομένων σε εξωτερικό server. Μην διαγράφετε τα δεδομένα ιστοσελίδων του browser χωρίς προηγούμενο αντίγραφο, γιατί οι υπενθυμίσεις αποθηκεύονται στο `localStorage`.
