# Reminder — προσωπικές υπενθυμίσεις

Μια ελληνόφωνη, μπλε/σκούρα PWA για επαναλαμβανόμενες και μεμονωμένες υπενθυμίσεις.

## Πρώτη έκδοση
- Προσθήκη, αλλαγή, διαγραφή και παύση υπενθυμίσεων.
- Επανάληψη: μία φορά, καθημερινά, εργάσιμες, εβδομαδιαία, μηνιαία.
- Αποθήκευση **τοπικά στη συσκευή** και εξαγωγή/εισαγωγή αντιγράφου JSON.
- Πραγματική εγγραφή Web Push με άδεια χρήστη, δοκιμή Push από το Supabase.
- Το Supabase αποστέλλει προγραμματισμένες Push ειδοποιήσεις ανά λεπτό όταν η εφαρμογή είναι κλειστή, μόλις ενεργοποιηθεί το Push στη συσκευή.
- PWA manifest και service worker, με λήψη κρυπτογραφημένων Web Push.
- Ξεχωριστή αποθήκευση στο Supabase: `reminder_push_*` (χωρίς αλλαγές στα δεδομένα των άλλων εφαρμογών).

**Σημαντικό:** Το Push χρειάζεται ενεργοποίηση από κάθε συσκευή, υποστήριξη browser και επιτυχία εγγραφής στην υπηρεσία. Δεν έχει ελεγχθεί ακόμη σε φυσικό κινητό. Οι υπενθυμίσεις παραμένουν τοπικές ανά συσκευή και συγχρονίζονται μόνο με το πρόγραμμα Push της ίδιας συσκευής (δεν συγχρονίζονται αυτόματα μεταξύ υπολογιστή και κινητού). Η παράδοση Push εξαρτάται από σύνδεση, ρυθμίσεις μπαταρίας και υπηρεσία Push· δεν αποτελεί σύστημα συναγερμού ζωτικής σημασίας. Αν το Chrome προειδοποιεί για phishing, μην παρακάμψετε την προειδοποίηση.

## Δημοσίευση
GitHub → Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save. Η αναμενόμενη διεύθυνση είναι `https://seemsfunny21.github.io/reminder/` όταν ολοκληρωθεί η δημοσίευση.

## Δεδομένα και ιδιωτικότητα
Δεν υπάρχει σύνδεση λογαριασμού ή αποστολή δεδομένων σε εξωτερικό server. Μην διαγράφετε τα δεδομένα ιστοσελίδων του browser χωρίς προηγούμενο αντίγραφο, γιατί οι υπενθυμίσεις αποθηκεύονται στο `localStorage`.

## Υποδομή Push

- Endpoint: `https://zrbmsziipzabnniqcpav.supabase.co/functions/v1/reminder-push` (απομονωμένα από τα υπόλοιπα projects).
- Supabase Edge Function: [`supabase/functions/reminder-push/index.ts`](./supabase/functions/reminder-push/index.ts).
- Supabase pg_cron: `reminder-push-every-minute`.
- Το VAPID private key αποθηκεύεται αποκλειστικά στη βάση με RLS και δεν βρίσκεται στο δημόσιο GitHub.
- Κάθε εγκατάσταση έχει δικό της τυχαίο διακριτικό και το backend διατηρεί μόνο το SHA-256 του. Δεν απαιτείται λογαριασμός.
- Επαναφορά υπενθυμίσεων σε διαφορετική συσκευή: Εξαγωγή/Εισαγωγή αντιγράφου JSON, μετά ενεργοποίηση Push στη νέα συσκευή.
